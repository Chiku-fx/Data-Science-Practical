# Practical 4: Data visualisation

## Aim
Unique instructors, bar chart by division and scatter plots of age against evaluation.

## How to run
Open practical_04.ipynb in Jupyter Notebook or Google Colab and choose Run All. Requires pandas, numpy, scipy, matplotlib, seaborn and scikit-learn.
